你打开微信想回一条消息。45 分钟后你在看怎么做锅包肉。你连锅包肉都没吃过。

你点开 B 站搜 Rust 教程。两个小时后，你在看「猫咪第一次见到雪」。你没有猫。

你告诉自己今天要写完那个模块。凌晨 1 点你躺在床上刷手机，VSCode 还开着——今天新建了一个文件，删了，又新建了一个，写了 11 行，全删了。

**这不是效率问题。这是你不知道自己在浪费时间。而你不知道的原因，是你不敢知道。**

---

## 没人愿意面对这件事

你想过用时间记录软件。你装过 Toggl、试过番茄钟、甚至买过 RescueTime 的订阅。

三天后你都卸载了。原因是同一个：**它们让你手动记录，但你根本不想记。**

——因为你隐约知道，记录下来的数字会让你难堪。

你以为自己学了 4 小时，实际 1.5。你以为自己只是回了"几条消息"，微信实打实吞了你 2.3 小时。你以为自己在思考架构，其实是在刷 Twitter。

**人类对时间的感知，烂到连自己都骗得过。**

这不是你的错。人脑就是不适合感知时间——你能感觉到 5 分钟和 1 小时的区别，但你不能感觉到「今天的有效工作时间是 4.2 小时还是 6.5 小时」。这个差距，没有外部数据你永远不知道。

---

## 所以 ChallengeDaily 不问你"在干什么"

它直接看你的屏幕。

每隔 60 秒截一张图，用 AI 看懂你在写代码还是在逛淘宝，然后告诉你。全程不用你点任何按钮。

这不是"自动记录"——这是**把你变成旁观者，让你从上帝视角看自己的一天。**

当你第一次看到报告，冲击力远超你想像：

* 「今天学了 4 小时」——不，你学了 1.5 小时，剩下 2.5 小时是"打开教程→切 B 站→切微信→再也没回到教程"
* 「下午一直在码代码」——不，中间切了 17 次到浏览器
* 「这周很努力」——不，你的趋势线在往下走，已经连续三周了

**你不需要读时间管理书。你不需要学什么方法论。你只需要看见你自己。**

看见一次，胜过自我反思一年。

---

## 但"看见"只是第一步

你看见自己每天有 2.3 小时被微信吞掉。然后呢？

**ChallengeDaily 不是只告诉你"你废了"，它给你工具让你不再废。**

### 番茄钟：让你不切换

你最大的敌人不是不努力，是**切换**。VSCode → 微信 → 浏览器 → VSCode → GitHub → 微信，一天切 200 次，每次切换的认知成本是 3-5 分钟。

番茄钟把 25 分钟锁死在一个任务上。到了它弹窗提醒你休息 5 分钟。你已经切了？没打钩不算。白噪音辅助，专注模式直接屏蔽 B 站和抖音。

**不是帮你更努力。是让你没法不努力。**

### 待办 + 周计划：让你知道"然后干什么"

你最大的时间浪费不在"不想干活"上，在**"不知道干什么，于是开始刷手机"**上。

待办清单分三种模式：计时型（25 分钟搞定）、目标型（写到能跑为止）、习惯型（每天背 20 个单词）。周计划按月→周→日三级层级，拖拽分配。你打开电脑第一眼看到的就是今天要做什么，不是今天要看什么视频。

### 习惯打卡 + 成就系统：让你想回来

单独的习惯 App 你装了 3 个，全弃了。因为它们跟你的工作数据完全割裂。

ChallengeDaily 的习惯打卡和你的采集数据天然关联——你今天 8 个番茄，自动累计"专注达人"勋章。你连续 7 天日记，解锁"自我觉醒者"。这些不是游戏化噱头，是你的数据在替你说话。

### AI 日报：让你不用写日报

不是 ChatGPT 式的"今日总结"。是 AI 读完你今天的全部屏幕记录后，按 12 个类别自动分类，写成一份你只需要扫一眼就懂的日报。你把同样的数据喂给内置 AI 对话，可以问它"我这周会议占比为什么涨了""我应该怎么调整明天的安排"——它的回答基于你的真实行为，不是通用鸡汤。

### 桌面宠物 + 日记 + 深度洞察：让你不孤独

角落的透明小宠物实时显示你当前在干什么——"正在写代码"、"刚切到微信"。不是玩具，是让你对"当下"有直觉感知。

日记 AI 自动关联当日工作数据——你的反思不再是对着空白文本框硬编，是有数据做锚点的复盘。

周报和深度洞察告诉你"你这周的碎片化学习占 60%，建议减少并行任务"。基于 10 个学术框架量化分析，不是拍脑袋。

## 隐私问题不回避

- 截图分析完**立即删除**，本地不留一张
- 微信、飞书、密码管理器、银行页面**自动跳过不截**
- API Key 用 Windows DPAPI 加密，不是 .env 明文
- 所有数据在你电脑上，断网也正常跑
- 没接 Key 也能用，内置 30+ 规则自动分类

## 为什么是 Windows，为什么是现在

最好的时间工具 Timing / Rize / Daily 全部 Mac 独占。1.5 亿 Windows 用户没人管。

同时智谱 GLM-4V-Flash 视觉模型已能精准识别屏幕内容，且**完全免费**。以前烧钱的 AI 能力现在成本趋零。

## 跑起来

```bash
cd xiaohei-daily
pip install -r requirements.txt
cd client && npm install && npm run build && cd ..
python main.py
```

打开 http://127.0.0.1:58888。打包版去 [Releases](https://github.com/EXtreameChallenge/ChallengeDaily/releases)。

不配 Key 也能用。接智谱/DeepSeek/Qwen/Kimi 的 Key 开启 AI 视觉。
