> **不是时间记录工具，是你电脑上的第二个自己。**

---

2026 年了。你对自己银行卡的每一笔支出清清楚楚，对微信聊天记录如数家珍，连三年前随手拍的照片都整整齐齐躺在相册里。

唯独最重要的东西——**时间**——你连今天做了什么都说不上来。

你觉得今天学了 4 个小时，数据告诉你只学了 1.5。你觉得只回了"几条消息"，微信实际吞了你 2.3 个小时。你觉得自己很努力，但毕业三年，GitHub 上还是去年 fork 的几个空仓库。

**ChallengeDaily 不是来帮你"管理时间"的。是来让你看见真相的。**

---

## 它到底做了什么

每隔 60 秒，默默截一张你的屏幕，用 AI 视觉模型看懂你当下在做什么——写代码、刷视频、聊微信、看文档——自动归档到 12 个类别。一天下来，生成一份你的"行程报告"。

你什么都不用做。连"点一下开始"都省了。

但这只是引擎。真正让 ChallengeDaily 跟你用过的任何工具都不一样的是——**它不止记录，它替你输出。**

---

## 开一天看看

**早上 9:00**，打开电脑。角落蹲着一只小宠物，告诉你"已经在采集了"。不用管它，照常用电脑。

**上午 9:05**，看一眼今天的**待办清单**。昨天没做完的"重构登录模块"自动排在最前面。点一下开始计时，25 分钟番茄钟启动。到点它弹窗提醒你休息 5 分钟——不是打断你，是怕你坐死。

**上午 10:30**，习惯追踪提醒你"今天还没喝水"。你点了打卡，成就系统悄悄累计——再坚持 3 天就解锁"连续喝水周"徽章。

**下午 2:00**，打开**专注模式**——选一个白噪音，把 B 站、抖音、Steam 全部屏蔽。屏幕上只剩 VSCode。这个模式强制你在接下来 25 分钟内只做一件事。

**晚上 10:00**，打开主界面。第一眼是今天的 **24 小时热力图**——最高峰在下午 2 点到 4 点，原来你效率最高的时段在这。旁边是一份跟竞品完全不同的东西：

```
📅 2026年7月9日 AI 日报

🕐 开发 3.2h — 修了用户模块 3 个 bug，重构登录页
🕐 沟通 1.8h — 微信/飞书讨论产品需求
🕐 学习 1.5h — Rust 所有权机制教程（浏览，建议下周安排深度练习）
🕐 休息 0.8h — B 站刷了几个视频

✅ 有效时间 6.5h  🔥 8 个番茄
📊 比昨天 +12%  |  本周累计 32h
```

**晚上 10:30**，写今天的**日记**——心情、天气、今天遇到的亮点。AI 自动把今天的采集数据关联进去，你的日记不再是空想，是有数据支撑的反思。

**每周日晚上**，周报自动生成。不只是时间分布，还有**深度洞察**——基于 10 个心理学/教育学框架的量化分析，告诉你"这周的碎片化学习占比 60%，建议减少并行任务"。你可以把这些分析喂给**内置 AI 对话**，问它"我下周应该怎么调整"。

**每月 1 号**，AI 给你做一份**用户画像**更新。你第一次看到一个客观版本："这个月你的主要工作类型是前端开发（45%），会议占比上升到 18%，代码提交集中在下午。"

## 为什么只有 Windows

这个赛道最好的产品——Timing、Rize、Daily——全部 Mac 独占。1.5 亿 Windows 用户没人管。

同时 2026 年智谱 GLM-4V-Flash 级别的视觉模型已经能精准识别屏幕内容，而且**完全免费**。以前要烧钱的 AI 能力，现在成本趋近于零。

**技术窗口开了，Windows 用户却没有对应的产品。** ChallengeDaily 就是来填这个坑的。

## 关于隐私：丑话说前面

- 截图**分析完立即删除**，没有一张存留
- 微信、飞书、密码管理器、银行页面**自动跳过**，根本不截
- API Key 用 Windows DPAPI 加密存储——不是 .env 明文，不存云端
- 所有数据全在你电脑上，断网也能正常用
- 没接 Key 也能用：内置 30+ 应用规则自动分类

## 部署

```bash
cd xiaohei-daily
pip install -r requirements.txt
cd client && npm install && npm run build && cd ..
python main.py
```

打开 http://127.0.0.1:58888 ，数据已经在采了。打包版去 [Releases](https://github.com/EXtreameChallenge/ChallengeDaily/releases) 下载 Setup.exe，需 Python 3.10+。

不配 AI 也能用（应用规则分类）。要开 AI 视觉识别，在设置里填智谱 GLM-4V-Flash 或 DeepSeek/Qwen/Kimi 的 Key，API Key 用 DPAPI 加密存储。

## 技术摘要

> 3 轮深度审计 + 30+ 项 Loop Engineering 修复，核心链路在自己环境连续验证通过。

| 层 | 技术 |
|----|------|
| 桌面 | Electron 31 |
| 前端 | React 18 + TypeScript + Vite 5 + Tailwind CSS 3 |
| 后端 | Python 3.11 + Flask 3 + Waitress |
| 数据库 | SQLite WAL（23 张表，Schema 版本管理） |
| AI | OpenAI 兼容协议（默认 GLM-4V-Flash） |
| 截图 | mss + Pillow（去重） |
| 系统 | Win32 API（多窗口枚举 + 面积分摊） |
| 安全 | Windows DPAPI |
