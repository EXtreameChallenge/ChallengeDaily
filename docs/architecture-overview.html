关键设计决策

架构选择
桌面优先
Electron + Python 后端，而非纯 Web SaaS，因为需要截屏 API 访问
单用户本地
Token 鉴权但 localhost 豁免，本地即唯一用户，简化权限模型
SQLite WAL
WAL 模式支持读写并发，避免采集器写入阻塞查询
懒加载
36 页面全部 lazy import，首屏只加载 Overview（~350KB）
SSE 实时
EventSource 推送采集器状态，替代轮询减少延迟
数据一致性策略
活动记录
activities 为主表，app_usage 为聚合视图，数据从 activities 派生
软删除
activities_deleted 保留 30 天，支持误删恢复
FTS 索引
reports_fts / doc_chunks_fts 全文检索，关键词搜索日报和知识库
AI 缓存
profile_analysis_cache 避免重复调用 AI 分析同一画像
熔断保护
AI 连续失败 5 次触发熔断，指数退避冷却，防止 API 费用暴涨
