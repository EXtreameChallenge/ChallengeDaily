# 01 · 项目总览

## 是什么
ChallengeDaily —— 「AI 替你记录每一天」的 Windows 桌面应用：自动记录电脑使用行为，生成每日回顾，帮助用户看清时间去哪了。

## 技术栈
- **后端**：Python 3.11（`main.py` 入口：调度器 + HTTP 服务；`server.py`、`routes/`、`services/`、`core/`）
- **前端**：Electron 31 + React + Vite（`client/`）
- **测试**：pytest（`tests/`，含 `conftest.py`）；前端 Jest（`cd client && npm test`）
- **许可**：MIT

## 版本与仓库
- 当前版本真源：`client/package.json` → `version`
- 远端：`origin` = https://github.com/EXtreameChallenge/ChallengeDaily ；`gitee` = https://gitee.com/EXtreameChallenge/ChallengeDaily ；`gitcode` = https://gitcode.com/EXtreameChallenge/ChallengeDaily

## 常用命令（项目根 `ChallengeDaily/`）
```powershell
cd client; npm run dev      # 前端开发（vite + electron）
cd client; npm run build    # 打包
cd client; npm run test     # 前端 Jest
python -m pytest tests -q   # 后端测试（按需）
python -m py_compile <file> # 改完 Python 单文件语法自检
cd client; npm run bump     # 版本号 +1（第三段）
```
