## 是什么
ChallengeDaily —— Windows 独占 AI 自动时间记录桌面应用（对标 RescueTime/Timing/Rize 的 Windows 空缺）。
每 30~120s 自适应截屏 + 窗口切换事件驱动 → GLM-4V 视觉分类 12 类 → 时间线/热力图/日报/洞察。
**单人自用，全量采集模式**（用户拍板：exclude_apps 默认空，隐私三开关默认关，保留可配置）。灵感来源 samlaying/xiaohei-daily（macOS）。

## 技术栈
- 后端：Python 3.11 + Flask 3 + SQLite WAL；B34 包结构化（根 py 129→6，core/services/integrations 分层，124 条懒别名兼容旧 import）
- 前端：Electron 31 + React 18 + Vite 5 + TS；40 页面/34 组件；glass 玻璃拟态
- 测试：pytest **219 passed 基线**（`python -m pytest -o addopts="" -q`，约 86s）；前端 jest（现状不确定）
- 许可：MIT
