ChallengeDaily Web Tracker 设置

配置后端连接、追踪精度与分类规则

连接配置

ChallengeDaily 后端服务地址，默认 http://127.0.0.1:59300
仅当后端设置了 CHALLENGE_WEB_TOKEN 环境变量时才需要填写

追踪配置

超过此时长无操作则停止计时（AFK）
每行一个，匹配域名包含该关键字的页面将不被追踪

自定义域名分类规则

JSON 对象，键为域名关键字，值为分类。优先级高于内置规则。内置规则：github/gitlab→开发，stackoverflow→学习，gmail/outlook→沟通，notion/docs.google→文档，youtube/bilibili→娱乐

数据管理

导出 chrome.storage.local 中的待发送队列与离线缓存（不含后端已存储数据）
